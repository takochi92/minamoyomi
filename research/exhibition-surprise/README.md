# 本人比の展示変化

初回結果は `REPORT.md`、全選手・全期の展示集計と条件に一致したレースは `statistics.json.gz`。

```bash
python -m tools.exhibition_surprise
python -m scraper.history --stats-only
python -m pytest -q tests
```

## 保存形式

- `profiles.terms[級別適用期]`: 審査期間 `from/to`、級別適用期間 `applies_from/applies_to`、実際に記録のある範囲、展示6艇が揃うレース数。
- 各期の `players[登番]`: `n` 展示数、`top1` 同率を含む1位数、`solo1` 単独1位数、`rank_sum` 順位合計、`dev_sum` レース平均との差の合計（秒）、`dev_sq` その二乗和、`wins` 1着数、`top3` 3着内数。
- 展示1位率は `top1/n`、平均展示順位は `rank_sum/n`、本人の通常展示差は `dev_sum/n`。
- `parameters`: 条件を固定。直前2期・展示100走以上・普段1位率10%以下・本人比0.03秒改善。
- `groups`: 前半／後半・コース別の各固定条件の件数、1着数・3着内数、着率、粗い実力補正基準、Wilson95%区間。
- `rare_solo1_events`: 該当走の日付・場・レース・登番・枠・実進入、参照期、参照展示数・1位率、順位改善・展示差変化、結果。回収率ではない。

## 期の扱い

公式の級別審査に合わせ、5月1日〜10月31日を翌年前期の審査期間、11月1日〜翌4月30日を翌年後期の審査期間として分類。
級別適用期の名前と、その集計対象期間を混同しないよう両方を保存します。
養成期は対象外。期途中の数字は途中集計です。保存されていない過去日・レースを0回出走として補完しません。

## 未来の混入と意図の断定を防ぐ

当該走を判定する際は、その前に終わった2期だけを参照します。
当該期の終わった後の展示1位率を、同じ期の過去レースに戻して使いません。
低い展示1位率は、選手の調整・出走条件・割り当てモーターなどの影響も含みます。「隠す人」の認定には使いません。
平均からの展示差は本人比の参考値で、行き足や伸びの直接測定ではありません。

`scraper.history.build_exstats` は従来の直近2年集計 `r` を維持し、別フィールド `term_profiles` を追加します。
既存の `load_exstats()` やサイト表示との互換性を保ちます。期別の追加統計は毎朝の既存履歴処理で再集計されます。
今回のコードは本人比の研究用で、買い目・予想係数・金銀枠は変更しません。

一般的な展示1位の効果と、本人比の珍しい1位による追加効果は別に検証する必要があります。
今回の率の差だけで機力の因果関係や市場を上回る確率を証明しません。
3連単回収率は、締切前の入力・判断時オッズ・固定買い目・購入額・返還を含む今後の記録で評価します。
