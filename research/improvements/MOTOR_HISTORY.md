# モーター使用履歴の拡張（2026-10-25）

- 従来は motor.build の meets が直近2期間、画面も2期間だけを表示していた。
- 予想用の既存集計は維持し、表示専用 history に保存済みの全使用記録を追加。
- 450日内の交換推定日以降を対象とする。同一号機でも交換前の記録は混ぜない。
- 全24場で交換推定日を検出。2026-10-25再集計で1,513基に履歴あり。
- 他艇の号機不明を理由に、確認できる艇の履歴まで捨てない。
- 使用者が変わる、または前の使用から3日以上空くと別期間。公式節日程とは区別して表示。
- 使用者の交代は省略しない。全使用期間を新しい順に並べ、着順の詳細を折りたたむ。
- 日付・R番号付きの着順から公式結果へリンク。欠場・事故の記録も残す。
- 表示用出走回数と連対率はS0/L0/K0を分母から除外。予想用のn/top2/top3は変更しない。
  [公式の除外説明](https://www.boatrace.jp/owpc/pc/site/news/2016/11/492/)
- 毎朝の既存 history → fstart → motor 処理で更新。開催当日の速報ではない。
- 交換日は0％機歴からの推定。公式確認済み日付はmotor_renewals.jsonで管理し、
  推定世代の日付が一致するときだけ確認済みと表示。将来の交換へ確認状態を引き継がない。
- 履歴を保存済み件数と共に提示するが、全公式記録との完全照合・欠落ゼロを保証しない。
