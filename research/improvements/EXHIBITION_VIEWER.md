# 展示映像の専用ページと原動画時刻（2026-10-26）

## 実装済み

- `/exhibition.html` を生成する。日付・24場・1〜12Rを指定し、収録したレースだけ表示。URLのクエリでもレースを指定できる。
- 通常は再生・艇・速度・区間・拡大だけの閲覧モード。端点指定、担当者、書出しなどは開発用確認画面へ分離。
- 場・日付・レースを変えたら直前の映像を破棄。別レースを表示したままにしない。未収録は未収録、無効な日付は入力案内。
- レースページ側は収録が公開承認されたレースの展示欄に小さな入口リンクだけを追加。出走表へ動画・タイム一覧を増設しない。現状は公開登録0件なので本番の入口はまだ出ない。
- `site/data/exhibition/index.json` のrecordsで登録。日付・場・R・ローカルassetを照合し、公開には `publish: true` と `rights_verified: true` を要求。確認用は別のローカル出力。リンク先は相対HTMLに限定し、外部URL・親フォルダ参照を拒否。
- 別ページのiframeは `allow-scripts` のみ。子からの高さ調節は表示中のiframeからのメッセージだけを受け付ける。描画寸法の検査は別途必要。
- 過去ページの再利用キーに展示映像の登録状況も含める。予想・購入・成績の計算は変更しない。

## 原動画の時刻で測る

`tools/extract_turn_frames.py` はローカル原動画から、実際のデコードPTSとtime_base、画像sha256を抽出する。一定FPSから時刻を推測せず、コマを複製・補間しない。抽出対象は45秒以内、ローカル動画コンテナのみで、外部通信・プレイリスト・原動画の上書きは行わない。

```sh
python -m tools.extract_turn_frames --video <local-original.mp4> \
  --start 245 --end 271 --output <new-empty-directory>
```

`tools/build_turn_review.py` は従来の画面キャプチャと、このPTS付きschema2を区別して読み込む。原動画フレームのsha256と寸法を照合。入力された追跡候補時刻も同じ原動画の時刻である必要があり、古いキャプチャの候補を無検証で流用しない。

正確なPTSは「そのファイル内の時刻が分かる」ことを意味する。編集されたスロー動画から抽出しても実走タイムにはならない。このため `origin_verified` と `editing_speed_verified` は抽出時falseで、両方が確認されるまで公開判定を通さない。

変動するコマ間隔を持つ合成動画で0,.1,.2,.3,.4,.8,.9,1,1.1,1.2秒が保持されること、途中だけの抽出でも元の時刻が維持されることを検査。これは抽出処理の検査であり、平和島の測定精度を確認した結果ではない。

## 現在の素材と具体的な未解決点（取得成功後の最新状態）

- 確認版は10月26日平和島1Rのネイティブ動画へ更新。プレイヤーで表示済みの配信先から対象36秒・6断片だけ取得。HTTPSの検証を維持したPythonの通常取得で原断片とAES-128の通常再生用キーを受信し、ネットワークを使わないローカル処理で復号・映像抽出できた。アクセス制限やライセンス確認の回避は行っていない。
- 配信断片、キー、具体的な配信URL、動画自体は公開コード・チャットに載せない。これを継続取得・公開配信の許諾取得と混同しない。
- 854×480、time_base=1/90000、26秒・780コマをPTS付きで抽出。確認ページは6艇645コマ。旧396枚のキャプチャ版は別ファイルに保持し、別素材の下書きを読み込ませない。
- 公式の通常UIから1Rを選択し、原動画取得を試みた。ブラウザの保存機能はiframeのblob非対応、プレイヤー単体でも失敗。表示済み素材一覧では直接videoファイルを取得できない。
- ffmpegの直接HTTPS取得は証明書確認で失敗したが、証明書検証を行うPythonのHTTPS取得は成功した。TLS検証を無効にはしていない。ローカルの自分で作成したプレイリストに限り、拡張子をts/m3u8/binとプロトコルをfile/crypto/dataに限定して処理した。
- ３号艇は艇首・艇尾の単独手動指定で再計算し、入り1.8秒・出口2.0秒（映像内参考値）。B通過で旧追跡枠中央のずれを避けた。指定点、前後コマPTS、原ファイルと画像の指紋を `research/exhibition-video/heiwajima-20261026-1R/native-boat3-example.json` に保存。これは原動画内での単独担当者の例で、独立照合・編集速度確認は未完了、正式タイムでも機力順位でもない。
- 原断片のPTSは56666秒台から始まる。プレイリストの経過240秒に相当する開始位置を候補探索用に対応付け、各計測は実際のPTS差から計算した。画面キャプチャ時刻やフレーム番号から秒数を再推定していない。
- 未使用レースの誤差評価、カメラ固定点の独立検査、全6艇の端点照合は未完了。原動画が取れたことだけで公開の条件を満たしたとは扱わない。
- 平和島FAQに映像素材使用の案内があっても、BOATCASTからの継続自動取得・再配信の条件まで確認済みとは扱わない。外部への問い合わせは送っていない。

## 公開状況

ソースとローカル確認版を作成。本番へのpush・公開は行っていない。映像を含む約40MBのHTMLは開発用で、一般向け配信方式としてそのまま採用しない。公開は利用可能な原動画経路・権利条件・性能確認と合わせて別途行う。
