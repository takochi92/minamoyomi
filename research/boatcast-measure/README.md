# BOATCAST 展示リプレイからの実測（伸び・立ち上がり）

公式に無い「伸び」「立ち上がり」を、BOATCAST 公式の展示リプレイ（周回展示）から測る。
保存するのは**数値だけ**（動画・画像は保存しない）。行の形は `scraper/independent_metrics.py` と同じ。

## 1コマンド

```sh
python -m tools.boatcast_measure run --date 20261114 --venue 04            # 全レース
python -m tools.boatcast_measure run --date 20261114 --venue 04 --races 3,4 --store PRIVATE/metrics
python -m tools.boatcast_measure compare --files research/boatcast-measure/20261114-04.json   # 公式との突き合わせ
```

流れ：Chrome（ポート 9454・自分のプロファイル）→ 480p を4倍速で通して場面分け → 1080p を 0.5倍速で、
固定カメラの場面だけ全コマ → 測る道すじの点の値（数値）→ 艇ごとの曲線 → 区間タイム → 行データ →
自己点検（読み戻し・行の検査・1レース2艇以上）→ 一時ファイル削除。出力は `research/boatcast-measure/<日付>-<場>.json`。
`rows` が採用した値、`report` が全艇（欠測の理由・解像度・コマ数・コマ抜け）。

## 測り方（艇を1コマずつ追わない）

周回展示には、場ごとに**動かない固定カメラ**の場面がある（平和島：1マークを上から見るカメラ、直線を横から見るカメラ）。
その場面の全コマで、決めた「道すじ」（中心線＋左右の帯）の画素だけを読み、横＝道すじの位置・縦＝時刻 の画にする。
艇は1本の曲線になる。曲線に2次式を当てはめ、道すじ上の2点（ゲート）を通る時刻の差が区間タイム。

| 場面 | 項目 | 曲線の出し方 | 理由 |
|---|---|---|---|
| 直線（横から） | `straight`（伸び） | 先頭：その点が急に明るくなった時刻（引き波の先頭＝艇首） | 艇は1隻ずつ、同じ線を通る。約3.5秒と長い区間が取れる |
| 1マーク（上から） | `acceleration`（立ち上がり） | 動き：2コマで大きく変わった画素の数の山（艇そのもの） | 前の艇の引き波が重なり、「最初に明るくなる所」があいまい。古い引き波はゆっくりなので動きでは消える |

艇番：1マークは乗り手の色（赤=3・青=4・黄=5。黄のあとの青っぽい色=6）を目印にし、白・黒は目印の間を順番で埋める。
数が合わない所は欠測（推測しない）。同じ色が2回出たら、その色は目印にしない。直線は、6本そろったときだけ順番で決める。

欠測にする艇（理由を `report` に残す）：艇番が決まらない／曲線のばらつきが 1.6コマ超／2つのゲートを覆っていない／
覆う割合が半分未満／（直線）線のずれを戻したあとも 30px 超ずれている／その場面でコマ抜けが1%超／解像度が 1920×1080 でない。

**採用していない項目の数字は評価に入れない**：profile の各場面に `adopted`（公式と合ったか）がある。`run --store` は `adopted: true` の項目だけを貯める。
いまは伸び・立ち上がりとも `false`（下の結果）。

場の設定は `tools/boatcast/profiles/<場コード>.json`：場面の目印（48×27 の灰色の値）、道すじ、ゲート。

## 結果（2026-11-14 時点。平和島 11/13・11/14 の24レース）

### 取得と再現性（合格）

| 項目 | 結果 |
|---|---|
| 取得 | 24/24 レース。コマ抜けは場面あたり 0〜1（0.5倍速）。解像度は全場面 1920×1080 |
| 同じレースを2回取得（11/14 11R、別々に再生） | 区間タイムの差：多くの艇で 0.000〜0.003 秒。最大 0.014 秒（1マーク）・0.019 秒（直線） |
| 自己点検 | 読み戻し一致・行の検査・1レース2艇以上。艇番の重複（色の取り違え）を検出して直した |

### 公式との突き合わせ（不合格。採用の基準：順位相関 0.6 以上）

レース内の差（平均からのずれ）どうしの相関。`python -m tools.boatcast_measure compare` で再現できる。

| 実測 | 公式 | レース | 艇 | 順位相関（レース平均） | 相関（全体） |
|---|---|---|---|---|---|
| 伸び（直線カメラ・線のずれ補正） | 直線 | 10 | 49 | **+0.28** | +0.23 |
| 同上（11/13 だけ。補正の傾きは 11/14 で決めたもの） | 直線 | 2 | 9 | +0.60 | +0.44 |
| 伸び | 展示 | 11 | 53 | −0.09 | −0.18 |
| 立ち上がり（1マーク出口の通過時間） | 立ち上がり指数（直線−展示） | 11 | 46 | **+0.06** | +0.08 |

目安：平和島の公式どうし（直線 と 展示）の順位相関は、118レースで平均 **+0.12**。1回の展示はそれだけばらつく。

判断：
- **伸び**：向きは公式の直線と合う（+0.2〜0.3）が、基準 0.6 に届かない。直線カメラの区間と公式の「直線」の区間が同じか不明。
  横から見たカメラでは、艇の走る線（カメラからの距離）で横切る時間が 1px あたり約 0.37% 変わり、これがモーター差（約0.75%）より大きい。
  線の位置をもっと細かく測れれば精度が上がる見込み。**まだ採用しない**（数字は `rows` に貯まるが、評価には使わない）。
- **立ち上がり**：1マーク出口の通過時間は、公式の立ち上がり指数と**合わない**。走る線（大回り・小回り）で r=0.42 変わり、選手の腕の成分が大きい。
  ほかに試した形（線で補正・出口の速さの伸び）も、11/14 の中で公式と一貫しなかった。**採用しない**。

### 分かった詰まり

- 1マークの固定カメラ：日によって水面が荒れ、動きの数え方の下限（8）で取れる艇が変わる（11/14 は 41 本、11/13 は 18 本）
- 一部のレースで固定カメラの場面が短い・途中で切れる（11/13 9R・10R など）。場面が短いと艇がそろわず、色の目印も足りない
- 白（1号艇）と黒（2号艇）は色で区別できない。赤・青・黄が見えないと、艇番を決められず欠測
- 直線カメラは艇の線のずれが大きい。1号艇はほかと違う線を走ることが多い
