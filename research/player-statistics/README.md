# 選手・筋目の探索統計

初回集計結果は `REPORT.md`、全件の統計は `statistics.json.gz`。
公開サイト・本番予想を変更しない、再実行可能な調査ツールです。

```bash
python -m tools.player_research --split 20251001 --output research/player-statistics
python -m pytest -q tests
```

## 保存形式

- `audit`: 対象期間、分割日、元レース数、除外数、重複数。
- `statistics.train/test`: 前半・後半の独立集計。
- `course[登番|実進入コース]`: `[出走数, 1着数, 2着数, 3着数, 基準期待1着数]`。着外数は出走数から1〜3着数を引く。
- `escape[登番]`: イン逃げ件数 `n`、`second_コース`、`third_コース`。`ALL` は全選手。
- `loss[登番]`: インが逃げなかった件数 `n` と `勝ちコース_決まり手` の件数。「差され率」を求める場合の分母は `course[登番|1][0]`。`loss.n` ではない。
- `attack[登番|実進入コース|決まり手]`: まくり／まくり差し勝ち件数 `n`、イン着外件数 `in_out`、相手2・3着コース `pair_2着-3着`。`payout_sum` はその勝ちレースの払戻総和であり、利益・回収率ではない。
- `muscles[勝ちコース|決まり手]`: 相手2・3着コースの件数。
- `matchup[イン登番|3コースA1/非A1]`: 該当レース数 `n`、イン1着 `in_win`、2コース差し勝ち `two_sashi`、インと3コースの共倒れ `in_and_three_out`、3コース着外 `three_out`。
- `candidate_keys_selected_on_train`: 前半だけで選んだ50候補 `[登番, コース, 縮約差]`。
- `motors.recent_changes`: 同じ場・号機・更新期の直近2節。使用者の登番と走数、レース平均からの展示差、乗り手補正展示差、2連対率、基準からの縮約上振れ。

## 解釈上の制約

本番進入・決まり手は事後分類です。予想に使う際は締切前に保存した展示進入・気象・オッズから、その展開になる確率を別に推定する必要があります。
この調査では払戻から事後的に穴を選ばず、回収率も算出しません。事前の買い目・購入額・返還の記録なしに実運用の回収率を出さないでください。

コース巧者の基準は前半データで固定した場・コース・当時級別・当時全国勝率の粗い区分です。
相手の実力、性別構成、節の格、チルト、スロー／ダッシュ、モーターなどは未補正。因果関係・最終的な優位性を示しません。
95%区間は個別の二項率のWilson区間で、多数候補の探索に対する補正は含みません。

モーターの節と更新日は保存履歴からの推定です。2日以内の開催間隔では節が結合する可能性があります。
乗り手の展示補正は当該日より前の履歴だけを使いますが、展示差は伸び・出足の直接測定ではありません。
2連対の基準には前半全体の集計を使い、過去期間の前向き予測成績とは扱いません。
各節5走以上でも少数のため、変化順位をそのまま買い目の根拠にしないでください。

このレポートを見て特徴や条件を変更した場合、後半も開発に使った期間になります。
新しいルールの評価には未使用の将来期間での固定買い目の検証が必要です。
