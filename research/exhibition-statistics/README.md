# 展示の組み合わせと外側展開の研究

`REPORT.md` が初回探索、`statistics.json.gz` が全151条件区分と外側候補のレース明細です。
`hypotheses.json` はユーザーに確認した古賀繁輝（4294）の観察仮説です。統計から動きや意図を断定したラベルではありません。

```bash
python -m scraper.research_snapshot
python -m tools.exhibition_research --split 20261003
python -m pytest -q tests
```

## 条件と分母

展示・直線・一周・まわり足を、同じレースの6艇内で順位付けします。欠損・0以下・非有限値のある項目は採用しません。
同タイムは同順位なので、上位2位の該当艇が3艇以上になる場合があります。
単項目4条件・2項目6条件・直線＋一周＋まわり足1条件を固定し、展示進入コースごとに集計します。
後から一番良かった条件だけを最終ルールにしません。項目別に欠測があるため、条件間で対象レースは異なります。

外側候補は、3／4コースの展示STが内側全艇より0.03秒以上早く、攻め候補の展示タイムが上位2位の場合。
攻め候補より外側の「一周＋まわり足」または「直線＋まわり足」がともに上位2位の艇を追跡します。
F／L・ST欠損のある比較は除外。展示STは本番STではなく、この条件は攻めの試行や内側の抵抗を認定するものではありません。

## 保存形式

`groups` の各区分は `phase/rule/course`、該当艇数 `n`、別レース数 `races`、1着数 `win`、3着内数 `top3`、各率とWilson95%区間を持ちます。
`baseline_*` は展示研究期間より前の保存済み結果で固定した、場・実進入コース・当時級別・当時全国勝率の粗い区分の基準です。
基準側は本番進入、対象側は展示進入のため、本番で進入が変わった場合もある点に注意してください。
`market_win_rate` は全120通りのオッズが揃ったレースだけで、逆数を正規化し当該艇の1着目を合計した参考値です。真の確率ではありません。
`market_n` を分母として使い、欠損を0確率にしません。旧形式の時刻は未確認であり、回収率の証拠に使いません。
`external_candidate_details` は条件に一致した候補のレース・攻めコース・受け手コース・結果を保存します。同じレースが複数条件に入る場合があります。

## 長期追跡

取得完了時刻が締切より前の場合のみ、`scraper.run` が研究用の入力スナップショットをレースJSONに保存します。
入力は出走表・展示・オリジナル展示・その時点で保存されたオッズで、結果は含めません。締切後や結果判明後に更新しません。
最新の入力に更新できるのは締切前だけです。各入力の元サイト側更新時刻や完全な同時刻性を保証するものではありません。

毎朝の既存履歴ワークフローで、完了レースを `history/exhibition_research/YYYYMM.jsonl.gz` に保存します。
サイトの短期保存分が消えてもこの履歴は残します。時刻付き入力は固定し、公式結果の訂正だけは更新できます。
旧レースは `legacy_unverified`、締切前の取得完了時刻を持つ新形式は `timestamped_pre_deadline` と区別します。
今回保存した1,818レースはすべて旧形式です。分析では展示進入と6艇の着順が揃う1,297レースを使用しました。

将来の未使用期間で、条件ごとの機力・選手力・人気との差、固定買い目・購入額・返還を含む回収率を確認してから予想へ反映します。
今回の変更は研究用の集計・入力保存で、買い目や金銀枠の表示は変更しません。
